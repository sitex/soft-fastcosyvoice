# soft-fastcosyvoice

Производительная производная CosyVoice с uv-проектом, fp16, потоковыми примерами и интеграциями TensorRT/TensorRT-LLM; модели используются из ModelScope или Hugging Face.

- Цель и локальные критерии: [PROJECT_GOAL.md](PROJECT_GOAL.md)
- Upstream: [Brakanier/FastCosyVoice](https://github.com/Brakanier/FastCosyVoice)
- Точки входа: [run_basic.py](run_basic.py), [run_fast.py](run_fast.py), [run_offline.py](run_offline.py), [webui.py](webui.py)
- Пакет и зависимости: [pyproject.toml](pyproject.toml), [uv.lock](uv.lock)
