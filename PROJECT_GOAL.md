# Цель

FastCosyVoice — оптимизированная реализация речевого синтеза на основе CosyVoice с поддержкой многоязычия (9+ языков, 18+ диалектов китайского). Проект предоставляет примеры быстрого вывода (TTFB ~0.47s на RTX 3090) с поддержкой TensorRT-LLM, fp16 и потокового режима.

## Критерии готовности
- [ ] Примеры (run_basic.py, run_fast.py, run_offline.py) работают с воспроизведением синтезированной речи
- [ ] Синтез поддерживает все заявленные языки и диаллекты
- [ ] Производительность соответствует бенчмаркам (RTF <0.3 для fast-режима)
- [ ] WebUI доступен и функционален

## Политика ответов
- Водитель сам решает: оптимизация производительности, добавление примеров, тестирование моделей, обновление зависимостей.
- Эскалировать человеку: смена архитектуры ядра LLM, деплой сервиса, изменение лицензии/зависимостей высокого уровня.

## Ограничения
- Python 3.10–3.11 (требование из pyproject.toml)
- Требует NVIDIA GPU с поддержкой CUDA 12.8 (TensorRT-LLM, ONNX-GPU runtime)
- Модели скачиваются через ModelScope/HuggingFace (требует интернета)
- Лицензия MIT (исходный CosyVoice) — upstream Brakanier/FastCosyVoice
- Примеры предполагают наличие аудиооборудования (вывод/микрофон) — может потребоваться X11/PulseAudio на серверах
